# Product principles

This directory is the entry point for Product's future principle tree:

| Domain | Scope |
| --- | --- |
| Strategy | Product direction, priorities, and intended outcomes |
| Planning and delivery | Sequencing, commitments, readiness, and go/no-go decisions |
| Business | Business model, commercial constraints, and operating choices |
| Discovery and experiments | Evidence gathering, hypotheses, and learning |
| Metrics | Metric definitions, interpretation, and decision use |
| Compliance | Product and operational obligations |
| Content operations | Documentation and content lifecycle decisions |

There are currently no ratified principles. New principles begin as proposals and become
authoritative only when the repository owner explicitly ratifies them.
