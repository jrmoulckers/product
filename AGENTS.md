# Product domain agent overlay

This repository is the Product domain authority for strategy, planning, business, discovery,
experiments, metrics, compliance obligations, delivery decisions, and content operations.

- Read and follow applicable local principles under `principles/` once they are authored.
- Treat the `jrmoulckers/.github` repository as the canonical source for shared agents, skills,
  and instructions; do not duplicate them here.
- Agents may propose principles. Only the repository owner may ratify them.
- Product defines obligations and outcomes. Hand technical mechanisms and evidence to
  Engineering, user-facing expression to Studio, and automation to `.github`.
- Do not place application code, UI implementation, technical mechanisms, or GitHub/Copilot/AI
  implementation in this repository.
